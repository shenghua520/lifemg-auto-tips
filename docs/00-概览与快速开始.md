# 00 · 概览与快速开始

## 站点信息

| 项 | 值 |
|----|----|
| 商城 | 晨光联盟商城 https://lifemg.cn |
| 形态 | Vue3 + Element Plus + Pinia + Vue Router + axios 的纯 SPA |
| 渲染 | `<div id="app"></div>` 全客户端渲染，curl 拿不到数据，必须跑浏览器 |
| 接口前缀 | `/v4/**` |
| 图片 CDN | `https://qiniupic-ssl.lifemg.cn/image/<hash>.png`（公开直链，无需签名） |
| 登录后落地 | `/`（商城前台），侧栏可进 `/pcadmin`（即时零售后台，终端角色只有"门店设置"） |
| 常见角色 | 终端(门店) / 配送中心 / 分公司 —— 本账号是**终端** |

## 5 分钟上手

```bash
npm install
cp config.example.js config.local.js

node scripts/00-login-save-state.js        # 登录 + 选门店 + 存登录态
node scripts/01-search-barcode.js 6944041509433
node scripts/02-export-item.js 6944041509433
```

`config.local.js`：

```js
module.exports = {
  phone: '<PHONE>',
  password: '<YOUR_PASSWORD>',       // 注意：本站密码可能带结尾标点，原样填
  storeName: '<STORE_NAME>', // 只有一个门店时也必须显式选一次
  outDir: 'output',
  concurrency: 4,
};
```

## 一个条码的完整链路

```
POST /v4/account/pwd_signin/pc       拿 pctoken
   ↓
GET  /v4/users/newShopList           拿门店列表 → 取 store_id
POST /v4/users/shop  (form-data)     选门店，否则 auth_storeid 一直是 0
   ↓
GET  /v4/search/searchGoodsV2?keyWords=<条码>&queryType=4
   ↓  data.secondItems[0].item_id
GET  /v4/item/{item_id}/newDetail    主图 / 轮播 / sku_list / 分类 / 价格 / 库存
GET  /v4/h5/item/{item_id}           detailHtml → 详情图
GET  /v4/item/itemArgs/{item_id}     品牌 / 包装规格 / 属性 / 建议零售价
   ↓
下载 10 张图 + 写 Excel
```

## 只读承诺

本仓库脚本全部是**只读采集**：

- 只发 `GET`（搜索/详情/门店列表）和 `POST /v4/users/shop`（选门店，只影响自己的会话）
- 不调用加购、下单、改价、上下架等任何写接口
- 不做删除、不做批量修改

## 环境要求

- Node ≥ 18
- 本机装了 Chrome（脚本用 `channel: 'chrome'` 启动；想用内置 chromium 就把 `lib/common.js` 里 `launch` 的 `channel` 去掉）
- Windows / macOS / Linux 均可，路径已用 `path.join` 处理
